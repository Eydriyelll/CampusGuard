# DSA lesson map

This folder is the honest checklist for lessons that are not part of the working app yet.
The implemented examples live in `../include/`; use the project README and the app's DSA
Lessons tab to find their exact files and line numbers.

## Planned examples

- **Circular linked list:** make the last node point back to the first, then cycle through items.
- **Binary tree:** limit each node to a left and right child.
- **Binary search tree:** keep smaller values on the left and larger values on the right.
- **AVL tree:** rebalance a search tree after insertions and removals.
- **Heap:** keep the highest- or lowest-priority item at the root.
- **Dijkstra shortest path:** compare total distance, rather than number of hallway connections.

These are learning placeholders, not structures used by CampusGuard. The current route finder
uses BFS, so it minimizes the number of connections and uses meters to break ties.
